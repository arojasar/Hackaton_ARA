# Mini proyecto – Análisis de datos pesqueros

**Autor:** Anthony Rojas  
**Curso:** Optimización de la ciencia marina en Latinoamérica a través de la ciencia abierta y el análisis de la situación pesquera

### Descripción
Análisis exploratorio de datos de prospección pesquera artesanal en el Archipiélago de San Andrés y Providencia. El proyecto incluye carga de datos, exploración básica, visualizaciones y una función documentada.

### Estructura
├── README.md
├── datos/
│   └── T_Maestra_Prov.xlsx

### Contenido del notebook
- Carga de datos
- Exploración básica
- Función propia documentada (`resumen_captura`)
- Visualizaciones (guardadas en la carpeta `Figuras/`)
- Conclusiones

### Requisitos
- Python 3
- pandas, matplotlib, seaborn
